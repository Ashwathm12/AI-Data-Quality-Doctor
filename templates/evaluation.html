Experimental Methodology & Reproducibility

  • Identical Test Beds: In each trial, both IQR and Isolation Forest receive the exact same feature matrix df.
  • Deterministic Seeds: Trials use a predictable sequence base_seed + run_index * 17 to guarantee 100% experimental reproducibility.
  • Configurable Thresholds:
    • IQR uses Tukey’s standard \(1.5 \times \text{IQR}\) boundary fence per numeric column.
    • Isolation Forest uses 100 base isolation trees with Scikit-learn’s contamination="auto" heuristic.
  • Mathematical Consistency: All confusion matrix partitions satisfy \(TP + FP + TN + FN = N\).

Limitations & Real-World Differences

  • Synthetic vs. Real Data: Synthetic datasets use controlled Gaussian clusters with shifted outliers. Real-world business data frequently contains non-linear correlations, multimodal distributions, and categorical attributes.
  • No Method is Universally Superior:
    • IQR is transparent, deterministic, and instantaneous, but treats columns independently (univariate).
    • Isolation Forest captures multi-feature interaction anomalies, but exhibits higher latency and slight stochastic variation.
  • Non-Destructive Principle: In production datasets, true labels are unknown. Detected outliers must always be flagged for domain expert review rather than deleted.
